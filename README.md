# 14년째 같은 자리 — 보행 고령자 사고다발지역의 재출현 구조 분석

**AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전** (한겨레 × 재단법인 숲과나눔) 제출작의 분석 코드입니다.

도로교통공단이 2013~2026년 지정한 보행노인 사고다발지역 6,282건을 전수 분석해,
위험이 특정 지점에 고정되어 있음을 확인하고 개선 우선순위 지수를 설계·검증했습니다.

---

## 핵심 결과

| 항목 | 값 |
| --- | --- |
| 원자료 | 6,282건 (2013~2026년, 14년) |
| 150m 클러스터링 후 고유 지점 | 3,094곳 |
| 3개 연도 이상 재출현 지점 | 577곳 (18.6%) |
| 14년 전 기간 연속 등재 | 9곳 |
| 재출현 지점의 누적 사망자 점유율 | 46.0% |
| 학교 인근 재출현율 : 전통시장 인근 | 10.0% : 53.7% |

### 검증된 가설

1. **재출현 지점이 실재함** — 3,094곳 중 577곳이 3개 연도 이상 반복 등재. 9곳은 14년 전 기간 연속.
2. **재출현 지점에 피해가 집중됨** — 지점당 누적 사망자가 단발 지점의 4.2배 (맨휘트니 U 검정, p < 0.001).
3. **상시 보호 제도의 유무가 재출현율을 가름** — 어린이보호구역이 적용되는 학교 인근 10.0%,
   제도 공백인 전통시장 인근 53.7% (카이제곱 295.2, p < 0.001 / 피셔 정확검정 오즈비 10.4).

### 우선순위 지수의 실증 검증

개선 대상 선정에 가장 직관적인 기준인 **누적 사망자 정렬이 표본외 예측에서 최하위**였습니다.
학습 구간으로 순위를 만들고 검증 구간의 실제 사망자를 얼마나 포착하는지 측정했으며,
분할 지점을 2019~2023년까지 5회 이동해 확인했습니다.

| 지수 | 평균 예측 커버율 | 평균 순위 |
| --- | --- | --- |
| **H 사상자 × 지속성 (PRI, 채택)** | **63.6%** | 2.5 |
| D 누적 사고 | 63.1% | 3.3 |
| F 누적 중상 | 62.6% | 3.2 |
| B 재출현 연도 수 | 62.3% | 3.5 |
| C 사망 × 지속성 | 57.0% | 7.0 |
| A 누적 사망 | 47.3% | 8.0 |
| (무작위 선택) | 10.3% | — |

동일하게 상위 300곳을 선정할 때 검증 구간(2022~2026년) 사망자 포착률은
채택 지수 **67.2%** (221/329명), 누적 사망자 정렬 **48.0%** (158/329명)입니다.

## 재현 방법

```bash
pip install -r requirements.txt
python run_all.py
```

`run_all.py`가 다음을 순서대로 실행합니다.

1. `src/download_data.py` — 원본 CSV 5종을 도로교통공단 개방시스템에서 내려받아 `data/`에 저장
2. `src/pipeline.py` — 인코딩 판별, 연도 파싱, 시도명 정규화, 150m 단일 연결 클러스터링
3. `src/analysis.py` — 가설 검정, 시설 유형 분류, 우선순위 산출, 민감도
4. `src/validate.py` — 시간 분할 검증으로 지수 8종의 표본외 예측력 비교
5. `src/figures.py` — 보고서 수록 그림 4종 생성

난수 시드는 42로 고정했습니다. 소요 시간은 일반 사양 PC 기준 약 2~3분입니다.

### 개별 실행

```bash
cd src
python download_data.py   # 데이터 수집
python pipeline.py        # 전처리 결과 확인
python analysis.py        # 가설 검정 결과 출력
python validate.py        # 지수 검증 표 출력
python figures.py         # 그림 생성
```

## 방법론 요약

**동일 지점 판정.** 지점 좌표가 연도마다 재산출되어 미세하게 이동하므로 좌표 일치로는 재출현 판정이
불가합니다. 단일 연결 클러스터링으로 150m 이내 지점을 동일 지점으로 병합했습니다.
반경 근거는 사고다발지역 폴리곤 반경이 약 100m 규모라는 점입니다.
민감도 검증 결과 100~250m 전 구간에서 결론 방향이 동일합니다.

**시설 유형 분류.** 지점명 텍스트에서 키워드를 단일 배정 규칙으로 추출합니다.
우선순위 순으로 하나만 배정해 중복 계상을 차단합니다. 외부 시설 위치 데이터가 필요 없습니다.

**지수 검증.** 표본내 적합도가 아니라 표본외 예측력으로 지수를 선택합니다.
학습 구간의 자료로 순위를 만들고 검증 구간의 실제 사망자 포착률을 측정합니다.

## 한계

- **노출량 미보정.** 재출현 지점이 통행량이 많은 지점일 가능성을 본 데이터만으로 배제할 수 없습니다.
  이 분석의 주장은 위험의 원인 규명이 아니라 위험의 공간적 고정성과 그에 따른 우선순위입니다.
- **시설 분류의 대리성.** 지점명 키워드는 실제 시설 위치가 아닌 표기 관행에 의존합니다.
  약국은 근린 상업지의 대리 지표로 판독해야 하며 약국 자체가 위험 요인은 아닙니다.
- **개입 효과 미검증.** 개선 대상 선정 기준의 우열을 검증했을 뿐,
  보호구역 지정 자체의 사고 저감 효과를 인과적으로 추정하지 않았습니다.

## AI 활용

데이터 탐색, 전처리 설계, 분석 설계와 구현, 결과 검증 단계에서 Claude(Anthropic)를 사용했습니다.
사용 서비스와 활용 범위, 주요 프롬프트는 분석보고서 4장에 기재했습니다.
AI가 생성한 코드와 수치는 전량 원본 CSV로 재계산해 대조했으며,
개인정보와 비공개 자료를 외부 AI 서비스에 입력하지 않았습니다.
